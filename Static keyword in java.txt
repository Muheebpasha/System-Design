In Java, the concepts of static classes and inheritance behave a bit differently compared to regular classes. Here's a clear explanation to your questions:

1. Can we do inheritance if we make a class static?
* In Java, top-level classes (non-inner classes) cannot be declared static.

* Only nested classes (inner classes defined inside another class) can be declared static.

* A static nested class behaves like a top-level class but is scoped inside the outer class.

* Static nested classes can be inherited (subclassed) like normal classes if they are public or accessible.

However, you cannot extend a static nested class from outside its enclosing class if it is not accessible due to access modifiers.

Summary:

You cannot declare a top-level class static.

You can declare nested classes static.

You can extend static nested classes (inheritance is allowed).

Static nested classes don’t have access to instance members of the outer class directly.

2. Why and when do we make a public static class in Java?
A public static nested class is used to logically group classes that are only used in one place, improving encapsulation and code organization.

It allows the nested class to be instantiated without an instance of the outer class.

Use cases include:

Defining helper or utility classes related to the outer class.

Implementing builder patterns or data structures within the enclosing class.

Avoiding memory overhead of an inner class that otherwise holds reference to the outer instance.

Since static nested classes do not have access to the outer class’s instance variables and methods, they are good for components that are conceptually tied to the outer class but don’t need its instance context.

Practical Example
java
public class OuterClass {

    // Static nested class
    public static class StaticNestedClass {
        public void display() {
            System.out.println("Inside static nested class");
        }
    }

    // Non-static inner class
    public class InnerClass {
        public void display() {
            System.out.println("Inside inner class");
        }
    }
}

// Usage:
OuterClass.StaticNestedClass nestedObject = new OuterClass.StaticNestedClass();
nestedObject.display();
Here, StaticNestedClass can be instantiated without an OuterClass instance.

This static nested class can be extended if needed.

Key Point about Non-static Inner Classes
A non-static inner class requires an instance of the outer class to be created.

This is because it implicitly holds a reference to the outer class instance.

Modified Example

    // Static nested class
    public static class StaticNestedClass {
        public void display() {
            System.out.println("Inside static nested class");
        }
    }

    // Non-static inner class
    public class InnerClass {
        public void display() {
            System.out.println("Inside inner class");
        }
    }

    public static void main(String[] args) {
        // Creating Static Nested Class object
        OuterClass.StaticNestedClass nestedObject = new OuterClass.StaticNestedClass();
        nestedObject.display();

        // Creating Non-static Inner Class object
        OuterClass outerObj = new OuterClass();  // Step 1: create outer class object
        OuterClass.InnerClass innerObj = outerObj.new InnerClass(); // Step 2: create inner class object
        innerObj.display();
    }
}

Non-static inner class object creation requires:

First, create an OuterClass instance.

Then, using that instance, create the InnerClass:

java
OuterClass.InnerClass innerObj = outerObj.new InnerClass();

1. What is static in Java?
The static keyword means "belongs to the class, not to any specific object".

This means:

A static member (variable, method, block, inner class) is shared across all objects of that class.

It is loaded into memory only once (when the class is loaded), not separately for each object.

2. Where Can We Use static?
static can be applied to:

Variables (Static Variables)

Methods (Static Methods)

Blocks (Static Blocks)

Nested Classes (Static Nested Classes)

2.1 Static Variables (Class Variables)
Used for properties that should be common for all objects.

Memory is allocated only once.

Example:

java
public class Employee {
    int id;
    String name;
    static String company = "Greynium"; // shared by all employees

    Employee(int id, String name) {
        this.id = id;
        this.name = name;
    }

    void display() {
        System.out.println(id + " " + name + " " + company);
    }

    public static void main(String[] args) {
        Employee e1 = new Employee(1, "Muheeb");
        Employee e2 = new Employee(2, "Maaz");

        e1.display();
        e2.display();
    }
}
Output:

text
1 Muheeb Greynium
2 Maaz Greynium
Note:
If we change company for one object:

java
e1.company = "Google";
This change will be reflected in all objects, because the variable is shared.

2.2 Static Methods
Can be called without creating an object.

Can only access static data (cannot directly access instance variables/methods).

Cannot use this or super.

Example:

java
public class MathUtil {
    static int square(int num) {
        return num * num;
    }

    public static void main(String[] args) {
        System.out.println(MathUtil.square(5)); // Call without object
    }
}
Important Rule:

java
class Test {
    int x = 5;

    static void show() {
        // System.out.println(x); ❌ ERROR - Cannot use non-static field
    }
}
2.3 Static Blocks
A static block is executed once when the class is loaded into memory.

Used for static initialization.

Example:

java
public class Demo {
    static int value;

    static {
        System.out.println("Static block executed");
        value = 42;
    }

    public static void main(String[] args) {
        System.out.println("Main method executed");
        System.out.println("Value: " + value);
    }
}
Output:

text
Static block executed
Main method executed
Value: 42
2.4 Static Nested Classes
A static nested class does not require an object of the outer class to be created.

Can only access static members of the outer class directly.

Example:

java
public class Outer {
    static int data = 30;

    static class Inner {
        void msg() {
            System.out.println("Data is: " + data);
        }
    }

    public static void main(String[] args) {
        Outer.Inner obj = new Outer.Inner();
        obj.msg();
    }
}
Output:

text
Data is: 30
3. Key Points
Belongs to class, not instance → shared across all objects.

static variable → same value for all objects.

static method → can be called without creating an object, can only access static members.

static block → runs once at class loading, used for initialization.

static nested class → behaves like a top-level class but without outer object reference.

this and super → not allowed inside a static context.

Complete Java Example – Demonstrating static
java
// File: StaticKeywordDemo.java

/**
 * Demonstrates the use of 'static' keyword in Java:
 * 1. Static Variable
 * 2. Static Method
 * 3. Static Block
 * 4. Static Nested Class
 */
public class StaticKeywordDemo {

    // 1. Static Variable (shared by all objects)
    static String companyName = "Greynium Technologies";

    // Non-static variable (belongs to each object separately)
    String employeeName;

    // Constructor
    public StaticKeywordDemo(String name) {
        this.employeeName = name;
    }

    // 2. Static Method (can be called without creating an object)
    public static void changeCompany(String newName) {
        companyName = newName; // can modify static variable
        System.out.println("Company name changed to: " + companyName);
    }

    // Instance method (can use both static and non-static variables)
    public void displayDetails() {
        System.out.println("Employee: " + employeeName + ", Company: " + companyName);
    }

    // 3. Static Block (runs once when class is loaded into memory)
    static {
        System.out.println("==== Static Block Executed ====");
        companyName = "Greynium Technologies";
        System.out.println("Initial company name set to: " + companyName);
    }

    // 4. Static Nested Class
    public static class HRDepartment {
        public void departmentInfo() {
            // Can access static variable of outer class directly
            System.out.println("HR Department of " + companyName);
        }
    }

    // Main method to run the demo
    public static void main(String[] args) {

        // Static block will run before this point automatically

        // Create objects
        StaticKeywordDemo emp1 = new StaticKeywordDemo("Muheeb");
        StaticKeywordDemo emp2 = new StaticKeywordDemo("Maaz");

        // Display details of employees
        emp1.displayDetails();
        emp2.displayDetails();

        // Call static method without creating object
        StaticKeywordDemo.changeCompany("Google");

        // Display again after change
        emp1.displayDetails();
        emp2.displayDetails();

        // Use Static Nested Class
        HRDepartment hr = new HRDepartment();
        hr.departmentInfo();
    }
}
How the program works
Static Variable: companyName is shared by all employees. Change it once, and it changes for all.

Static Method: changeCompany() changes the shared companyName.

Static Block: Executes only once, before main method runs, to initialize companyName.

Static Nested Class: HRDepartment can be used without creating an outer class instance to access static members.
