important Dockerfile instructions
FROM
WORKDIR
COPY
RUN
CMD
EXPOSE
ENV

============
1. FROM <image> => This specifies the base image that the build will extend.

2. WORKDIR <path> => This instructions specifies the "working directory" or the path in the image where files will be copied and commands will be executed.

3. COPY <host-path> <image-path> => This instruction tells the builder to run the specified command.

4. RUN <command> => This instruction tells the builder to run the specified command.

5. CMD ["<command>", "<argl>"] => This instructions sets the default command a container using this image will run.

6. EXPOSE <port-number> => This instruction sets configuration on the image that indicates a port the image would like to expose.

7. ENV <name> <value> => This instuction sets an environment variable that a running container will use.
