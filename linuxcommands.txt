ps aux | grep mongod

This is a common Linux command used to check if a process (in this case, mongod) is running.

ps => Process Status => Shows currently running processes

aux (options to ps) :
aux is a flag 

a => Show processes for all users, not just the current one.
u => Show the user who started each process.
x => Show processes not attached to a terminal (e.g., daemons, background tasks like mongod).

✅ | (pipe)
* Takes the output of the command on the left (ps aux)
* Sends it as input to the command on the right (grep mongod)

✅ grep mongod
* Searches for lines that contain the word mongod
* mongod is the MongoDB daemon process — the background server that listens for connections

🔍 Explanation:

    grep: search utility

    -r: recursive (search all subdirectories)

    -n: show line number

    -w: match whole words (optional here)

    .: current directory (you can replace with specific path)

    -e: pattern to search
    
===============================================================================
| Command              | Meaning                                              |
| -------------------- | ---------------------------------------------------- |
| `chmod u+w file.txt` | Add write permission to the owner                    |
| `chmod g-w file.txt` | Remove write permission from the group               |
| `chmod o+r file.txt` | Add read permission for others (world)               |
| `chmod a+x file.sh`  | Add execute permission for all (user, group, others) |
===============================================================================

u → user (the file owner)

+ → add

w → write permission

r → read permission

- → remove permission(minus)

a → All (user,group,others)
=======================================================================================
